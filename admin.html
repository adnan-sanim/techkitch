Firebase Rules Permission Required (30 Seconds Setup)

Since this is your personal Firebase project, by default Firestore blocks external writes. Go to the Rules tab in your Firebase Console and allow writes: 

rules_version = '2';
service cloud.firestore {
  match /databases/{database}/documents {
    match /{document=**} {
      allow read, write: if true;
    }
  }
}
